# Hanged-man
# ✿ Petal Hangman ✿

A cozy take on Hangman: guess the word before the flower loses all 6 petals. Written in **Python** and run in the browser with PyScript.

🌸 **[Play it live](https://soumyag777.github.io/Hanged-man/)**

## Features
- 🌸 Each wrong guess makes a petal fall, and the flower's face reacts
- 🧁 Word categories: sweet treats, cute animals, in the garden, cozy things
- ⌨️ Tap the on-screen keys or type on a keyboard
- 🏆 Wins and streak tracking, plus a dancing flower and confetti when you win

## Python practice
- **Lists:** the word bank and wrong guesses
- **Strings:** hiding and revealing letters (`"_ u n n _"`)
- **Sets:** remembering every letter already tried
- **Classes:** a `Game` class that keeps the rules separate from the visuals

## Built with
Python (`main.py`), HTML, and CSS. [PyScript](https://pyscript.net) runs real Python in the browser. Hosted on GitHub Pages.

## Design notes
I swapped the classic hangman drawing for a flower losing petals. It keeps the same tension, with a gentler, friendlier feel.
